# Manary - Amplify Chart Edition

Manary is a chart-management workspace for midwifery clinics. This edition mirrors the chart experience from the Supabase-backed project, but all breast-care and postpartum-care charts are stored locally in the browser via `localStorage`. Administrator authentication still runs on Amplify Auth (Amazon Cognito), and the UI remains a Next.js App Router application that deploys cleanly to AWS Amplify Hosting.

## Highlights
- Amplify Auth sign-in with the Amplify UI `Authenticator` component (Cognito under the hood).
- Local storage data model – charts are saved inside the browser (`manary-free-charts-state`), so no database or network is required after sign-in.
- Rich dashboard for creating, editing, browsing, and deleting breast-care / postpartum-care charts.
- Built-in chart templates that reproduce the Supabase reference layouts for quick previews or printing.
- Static-friendly build output ready for Amplify Hosting without custom scripting.

## Tech Stack
- Next.js 15 (App Router) + React 19
- AWS Amplify Auth + Amplify UI (`@aws-amplify/ui-react`)
- Tailwind CSS + shadcn/ui components
- TypeScript 5

## Amplify Auth Setup (follow the [AWS docs](https://docs.amplify.aws/react/build-a-backend/auth/))
1. **Install the Amplify CLI (Gen 2)** – `npm install -g @aws-amplify/cli`.
2. **Initialize the backend** – inside the repository run `amplify init` (or `amplify sandbox`) and choose the defaults for a JavaScript app.
3. **Add authentication** – run `amplify add auth` and choose **Default configuration** (email sign-in is a good default).
4. **Push the backend** – run `amplify push` (or `amplify deploy`) to create Cognito resources in AWS.
5. **Pull the outputs into the app** – `amplify pull --appId <appId> --envName <env>` (or accept the prompt after `amplify push`). This generates/updates `amplify_outputs.json`.
6. **Commit or securely store `amplify_outputs.json`** – the app imports this file at runtime. Replace the placeholder file checked into the repo with the real one generated by Amplify.

> The placeholder `amplify_outputs.json` in the repository only keeps TypeScript happy. Replace every `"REPLACE_ME"` value with the real data supplied by the Amplify CLI.

## Local Development
```bash
npm install
npm run dev
# visit http://localhost:3000
```

Ensure `amplify_outputs.json` is populated before starting the dev server; otherwise the Amplify Auth SDK cannot connect to your user pool.

## Sign-in Flow Summary
1. `/` renders contextual information along with the Amplify `Authenticator` sign-in experience.
2. After a successful sign-in, the user is redirected to `/dashboard`.
3. Clicking **サインアウト** calls `Authenticator`'s `signOut`, clears the Amplify session, and returns to `/`.

## Local Storage Schema
Chart data lives under `localStorage["manary-free-charts-state"]` and looks like:

```json
{
  "charts": [
    {
      "id": "uuid",
      "chartType": "breast",
      "patientName": "山田 花子",
      "patientId": "BC-0001",
      "visitDate": "2025-10-12",
      "practitionerName": "佐藤 仁美",
      "createdAt": "2025-10-12T09:30:00.000Z",
      "updatedAt": "2025-10-12T09:45:00.000Z",
      "data": {
        "breastMilkInterval": "3時間ごと",
        "nippleAreolaCondition": ["軽度の亀裂"],
        "careDetails": "搾乳指導 20分",
        "initialConsultationFee": true
      }
    }
  ]
}
```

Use your browser dev tools (Application → Storage → Local Storage) to back up or clear the chart data.

## Amplify Hosting Deployment
1. Connect the repository in Amplify Hosting (GitHub or manual).
2. Build settings:
   ```bash
   npm install
   npm run build
   ```
   Output directory: `out`
3. Copy your production `amplify_outputs.json` into the build environment (for example via the Amplify console’s file management or by storing it in the repo if acceptable).
4. Redeploy after replacing the placeholder outputs file.

### Manual Publish (Amplify CLI)
```bash
npm install -g @aws-amplify/cli
amplify init
amplify add auth
amplify push
npm install && npm run build
amplify publish              # uploads the ./out directory
```

## Troubleshooting
- **Authenticator loops back to `/`** – ensure `amplify_outputs.json` matches the environment you deployed with `amplify pull`.
- **Sign-in succeeds but the dashboard is blank** – make sure the authenticated user exists in the Cognito user pool created by Amplify.
- **Charts disappear after refresh** – the browser stores `localStorage` per domain/device; export or copy `manary-free-charts-state` before clearing storage.
