# Manary - Amplify Local Storage Edition

Manary is a reservation and client-management app tailored for midwifery clinics. This edition stores all reservation data in the browser via `localStorage`, while administrator authentication is powered by Amplify Auth (Amazon Cognito). The frontend runs on Next.js (App Router) and deploys cleanly to AWS Amplify Hosting.

## Highlights
- Amplify Auth sign-in via the Amplify UI `Authenticator` component (Cognito under the hood).
- Local storage data model – reservations and service definitions live inside the browser (`manary-local-app-state`).
- Dashboard tooling for confirming, cancelling, and deleting reservations.
- Public reservation form that instantly feeds the in-browser admin dashboard.
- Static-friendly build output that fits Amplify Hosting without extra scripting.

## Tech Stack
- Next.js 15 (App Router) + React 19
- AWS Amplify Auth + Amplify UI (`@aws-amplify/ui-react`)
- Tailwind CSS + shadcn/ui
- TypeScript 5

## Amplify Auth Setup (follow the [AWS docs](https://docs.amplify.aws/react/build-a-backend/auth/))
1. **Install the Amplify CLI (Gen 2)** – `npm install -g @aws-amplify/cli`.
2. **Initialize the backend** – inside the repository run `amplify init` (or `amplify sandbox` if you prefer the sandbox flow) and choose the defaults for a JavaScript app.
3. **Add authentication** – run `amplify add auth` and choose **Default configuration** (email sign-in is a good default).
4. **Push the backend** – run `amplify push` (or `amplify deploy`) to create the Cognito resources in AWS.
5. **Pull the outputs into the app** – run `amplify pull --appId <appId> --envName <env>` (or accept the prompt after `amplify push`). This generates/updates `amplify_outputs.json`.
6. **Commit or securely store `amplify_outputs.json`** – the app imports this file at runtime. Replace the placeholder file checked into the repo with the real one generated by Amplify.

> The placeholder `amplify_outputs.json` in the repository only keeps TypeScript happy. Replace every `"REPLACE_ME"` value with the real data supplied by the Amplify CLI.

## Local Development
```bash
npm install
npm run dev
# visit http://localhost:3000
```

Ensure `amplify_outputs.json` is populated before starting the dev server; otherwise the Amplify Auth SDK cannot connect to your user pool.

## Sign-in Flow Summary
1. `/` renders contextual information along with the Amplify `Authenticator` sign-in experience.
2. After a successful sign-in, the user is redirected to `/dashboard`.
3. Clicking **Sign out** calls `Authenticator`'s `signOut`, clears the Amplify session, and returns to `/`.

## Local Storage Schema
Reservation data lives under `localStorage["manary-local-app-state"]` and looks like:

```json
{
  "reservations": [
    {
      "id": "uuid",
      "patientName": "Jane Doe",
      "patientEmail": "sample@example.com",
      "serviceTypeId": "prenatal",
      "status": "pending"
    }
  ],
  "serviceTypes": [
    { "id": "prenatal", "name": "Prenatal check-up", "durationMinutes": 60 }
  ]
}
```

Use your browser dev tools (Application → Storage → Local Storage) or the **Reset Data** button in the dashboard to clear the sample data.

## Amplify Hosting Deployment
1. Connect the repository in Amplify Hosting (GitHub or manual).
2. Build settings:
   ```bash
   npm install
   npm run build
   ```
   Output directory: `out`
3. Copy your production `amplify_outputs.json` into the build environment (for example via the Amplify console’s file management or by storing it in the repo if acceptable).
4. Redeploy after replacing the placeholder outputs file.

### Manual Publish (Amplify CLI)
```bash
npm install -g @aws-amplify/cli
amplify init
amplify add auth
amplify push
npm install && npm run build
amplify publish              # uploads the ./out directory
```

## Troubleshooting
- **Authenticator loops back to `/`** – ensure `amplify_outputs.json` matches the environment you deployed with `amplify pull`.
- **Sign-in succeeds but dashboard is blank** – make sure the authenticated user exists in the Cognito user pool created by Amplify.
- **Data missing after refresh** – browsers store `localStorage` per domain/device; export or copy `manary-local-app-state` before clearing storage.
